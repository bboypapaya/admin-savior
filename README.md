# admin-savior
行政救星：純本機離線公文與雙證件圖片處理工具

本專案是一款專為行政人員設計的純前端 HTML 離線小工具。
核心宗旨是在 **「100% 不上傳個資、不透過任何伺服器」** 的極端安全環境下，協助使用者處理公文、證件等高資安敏感度的相片優化。

### 核心功能
* **公文/證件梯形校正**：將用手機拍歪的文件自動拉直並還原比例。
* **雙證件正反面合併**：一鍵將身分證、健保卡正反面照片拼接為單一圖檔。
* **隱私防護遮蔽**：支援局部馬賽克、去除個資、自訂滿版浮水印防止冒用。
* **高對比黑白優化**：智慧保留彩色公章，同時提升文字易讀性。
* **一鍵匯出A4滿版或1:1實際尺寸PDF**：匯出PDF檔，便於公務使用。
* **重點標註、舉行自由裁切**:重點標示、免去先列印後使用文具標示再掃描的繁瑣流程。
